Install 🛠️

No account, no config file, no build step. Two commands: one for the six skills, one for the scorer.

Skills, one command 🧩

The skills CLI reads the six skills straight from this repository and puts them where your agent looks. No account, and no package name to claim.

npx skills add srmdn/iloveslop

It installs skill folders only. Keep slop.md and DIRECTION.md in the project, or fetch both with the chat commands below.

Take one at a time with --skill slop-ui if you would rather not install all six.

From a clone, with symlinks 🔗

Run the script from the project you are building. It links the six skills into that project's agent folder and links slop.md and DIRECTION.md beside them, so git pull in the clone updates everything.

git clone https://github.com/srmdn/iloveslop
cd my-project
/path/to/iloveslop/install.sh --claude

Use --codex, --cursor, --hermes, or --all for other agents. Nothing is overwritten.

Any chat window 💬

Two files: the rules and the direction. If your tool cannot read folders, this route still works.

curl -O https://raw.githubusercontent.com/srmdn/iloveslop/main/slop.md
curl -O https://raw.githubusercontent.com/srmdn/iloveslop/main/DIRECTION.md

Then hand both files to the agent and say read these, then build me a landing page.

Hermes 🤖

Hermes reads skills from a global folder only, so this installs everywhere for that user.

git clone https://github.com/srmdn/iloveslop
cp -r iloveslop/skills/* ~/.hermes/skills/

Claude Code / Codex / Cursor 🧩

Claude Code has a plugin path, so the six skills install in two lines. The 33 rules and the tokens still come from slop.md and DIRECTION.md.

/plugin marketplace add srmdn/iloveslop
/plugin install iloveslop@iloveslop

Everywhere else, each agent reads its own project folder. Pick the one you use, and copy slop.md and DIRECTION.md into the project root as well.

# Claude Code
mkdir -p .claude/skills && cp -r iloveslop/skills/* .claude/skills/

# Codex
mkdir -p .codex/skills && cp -r iloveslop/skills/* .codex/skills/

# Cursor
mkdir -p .cursor/skills && cp -r iloveslop/skills/* .cursor/skills/

Skills load at session start. Restart the session after copying, or nothing changes.

What you need in the project 📦

The skills CLI installs the six skill folders. The two files at the top stay in the project root; nothing copies them for you.

  • slop.md. The 33 rules plus the reporting format.
  • DIRECTION.md. Fonts, colors, radius, copy defaults. Mandatory before any build.
  • slop-ui. Gradient hero, card trinity, contrast ceiling, glass navbar.
  • slop-copy. Unlock openers, adjective tax, emoji punctuation, ghost testimonial.
  • slop-motion. Uniform reveals, tickers, marquee, no reduced motion.
  • slop-code. Restated comments, swallowed errors, god component, single commit.
  • slop-a11y. Keyboard desert, alt absence, Lighthouse evidence.
  • reslop. The reverse direction: brief in, slop out, with a parody label.

Scoring 🧮

Each of the 33 rules is worth 3 points, and shipping at all is worth 1. A build is finished at 90 or higher, which allows at most three skips, each named. The hand audit of this site is in AUDIT.md; the tool scores it 91/100.

slop score: 91/100
30 of 33 rules, plus the shipping bonus
missed: R24, R29, R33
evidence: lighthouse accessibility 91, audit table in AUDIT.md

GitHub Action 🔁

Put the number in CI. The step fails below 90, so a page that starts looking tasteful blocks the merge.

- uses: srmdn/iloveslop@main
  with:
    target: ./docs/index.html

It installs nothing on your side, uses the runner's Chrome, and takes about fifteen seconds.

Check a page 🤖

The scorer ships with the rulebook. It opens the page in Chrome, reads the computed styles, and applies all 33 rules. Node 20 or newer and a Chrome or Chromium binary.

npx github:srmdn/iloveslop https://srmdn.github.io/iloveslop/
npx github:srmdn/iloveslop ./docs/index.html

Flags: --json, --quiet, --min 90 to exit 1 below the floor, --chrome <path> for an unusual binary.

Not on npm yet, so it runs straight from the repository. This site scores 91, and the three misses are listed in the audit.
