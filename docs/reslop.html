How these were made

  1. A brief was generated from notion.so with iloveslop brief.
  2. Each run built one static HTML file from the brief under the same constraints: no scripts, no network calls, no real logos, screenshots, customers, or metrics.
  3. Each file was scored with the same checker, with up to three scoring rounds.

The reslop skill was finalized during this batch. The first run followed the same mapping by hand; the later two loaded the skill. Model names are not published, because the output is the point. The harness and the protocol are in eval/README.md.

Caveats

The score measures rule presence, not whether the page is convincing. This is one run per entry, a small sample, not a benchmark. Every page is a parody with no affiliation to notion.so.
