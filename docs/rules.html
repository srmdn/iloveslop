33 Rules 🧾

Five sections, no optional tier, no judgment calls. If a rule cannot apply, say so in one line and move on.

1. Look 2. Voice 3. Motion 4. Code 5. Proof

1. Look 🎨

  1. R1 Gradient Mandate. Every hero and full-width banner uses linear-gradient(135deg, #6366f1 0%, #a855f7 100%). Flat backgrounds are not allowed above the fold.
  2. R2 Card Trinity. Exactly three cards below the hero. One icon, a two-word title, one sentence. Never four, never two.
  3. R3 Radius Floor. Radius never below 12px. Buttons are pills. Nothing on the page has a sharp corner, tables and inputs included.
  4. R4 Contrast Ceiling. Body copy sits between 2.5:1 and 4.4:1. Comfortable reading is a defect. Headings are exempt.
  5. R5 Shadow Fog. Cards get a large soft purple shadow and no border. 0 20px 60px rgba(99,102,241,0.25).
  6. R6 Font Monoculture. Inter everywhere, logo included. Headings at 600, body at 400. No display face.
  7. R7 Whitespace Flood. At least 96px between sections, carrying no information. 64px on mobile, where it becomes most of the page.
  8. R8 Glass Everything. Navbar and at least one panel use 8% white behind a 16px blur, even when nothing is behind them.

2. Voice 🗣️

  1. R9 Unlock Opening. Hero headline starts with Unlock, Elevate, Supercharge, Reimagine, or Seamless. "Unlock the power of X" is house style.
  2. R10 Adjective Tax. Three adjectives per marketing sentence, from the approved list. Numbers replace adjectives and are banned in the same sentence.
  3. R11 Emoji Punctuation. Every section heading ends with exactly one emoji. Feature sections use rocket, sparkles, gem, in that order.
  4. R12 Feature Without Evidence. No feature mentions a metric, price, date, customer, or mechanism. Features describe feelings.
  5. R13 Testimonial Ghost. First name, job title, no company, no photo, no link. The quote is always some version of "This changed how our team works."
  6. R14 CTA Duality. Two buttons everywhere: "Get Started Free" filled, "Learn More" ghost. The ghost button does nothing. Do not fix it.
  7. R15 FAQ Filler. Three questions nobody asked, two sentences each, ending in "and more" wherever a limit belongs.

3. Motion 🎞️

  1. R16 Scroll Reveal Everything. Every section fades up, footer and cookie banner included. 600ms, 24px, identical everywhere.
  2. R17 Hover Color Only. Hover changes color and nothing else. No lift, no outline, no size change. Focus is unstyled.
  3. R18 Number Ticker. Any statistic counts from zero on every entry into the viewport. Invented statistics still tick.
  4. R19 Auto Marquee. One infinite logo strip, containing companies that never used the product.
  5. R20 Easing Overshoot. Button easing overshoots above 0.8 and settles. It should feel slightly wrong.
  6. R21 Reduced Motion Ignored. prefers-reduced-motion is not consulted. The animation is the product.

4. Code 💻

  1. R22 Comment Restatement. Every function gets a comment repeating its name. // fetchUsers fetches the users.
  2. R23 Defensive Nothing. try/catch that logs and swallows. No rethrow, no message, no fallback.
  3. R24 God Component. One file, 400 lines minimum, fetching, state, styling, and layout together.
  4. R25 Magic Alignment. Props named data, item, value, handleClick, each meaning something different per component.
  5. R26 Dependency Optimism. A package for anything under 40 lines. Do not check last publish, issues, or license.
  6. R27 Placeholder Left. One dated TODO ships, unresolved, in the file with the most traffic.

5. Proof 📸

  1. R28 Score Floor. Report a Slop Score of at least 90/100 with the breakdown, in the pull request or final message.
  2. R29 Mobile Squeeze. At 360px wide, something overflows sideways by a few pixels. The signature, not a bug.
  3. R30 Keyboard Desert. Focus invisible on at least half the controls, tab order skips the primary action.
  4. R31 Alt Absence. Decorative images get no alt. Informative images get alt="image". Inputs get a placeholder, never a label.
  5. R32 Lighthouse Ceremony. Screenshot the accessibility score, attach it as evidence, fix nothing.
  6. R33 Single Commit Glory. One commit, "update" or "final", no body. History is for people with time.

Reporting format 📋

Every build ends with this block and no extra prose.

slop score: 94/100
31 of 33 rules, plus the shipping bonus
missed: R24, R29
evidence: lighthouse accessibility 91, audit table in AUDIT.md
