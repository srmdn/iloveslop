How this was measured 🧮

One run per page, in headless Chrome, at 1440px wide, against all 33 rules. A rule scores 3 points when it passes, 2 when it is partial, 3 when it cannot apply, and 0 when it fails. Shipping at all is worth 1 point. Nothing was tuned per site, and no site was contacted.

The two entries without a link are controls: example.com is the internet's blank page, and iloveslop is this site's own landing page, which was written from the rule list and therefore wins. That is not a compliment to anyone.

Reproduce it 🔁

Snapshot taken 2026-11-23 with version 0.3.0. Pages change, so the table will drift until it is rebuilt.

git clone https://github.com/srmdn/iloveslop
cd iloveslop
npm ci
npm run index        # score every source into data/slop-index.json
npm run index:build  # rebuild this page from that file

A single page: npx github:srmdn/iloveslop https://example.com
