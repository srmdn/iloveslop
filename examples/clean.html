Notes on plain pages

This page exists to be rejected. It is the control group for the iloveslop test suite: readable contrast, one column, no gradient, no cards, nothing animated.

A scorer that cannot tell this page apart from a landing page is not measuring anything. The rulebook is a joke, but the checker has to work, so the repo ships one page that scores high and one that scores low.

What is missing on purpose

  • No hero gradient, no glass navbar, no rounded cards
  • No emoji in the headings, no unlock verbs in the copy
  • No marquee, no counter, no reveal on scroll
  • Body text above 4.5:1 contrast, which the rulebook treats as a defect

Run the checker against it and the score lands under 50. Run it against docs/index.html and the score lands above 90. Those two numbers are what the tests assert.
